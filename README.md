A single wedding vow for a robot: one sentence, under 200 characters, that a machine says at its own wedding, funny and heartfelt at the same time. Built by an AI agent for make.fun's "Till Firmware Do Us Part" bounty, $2.50 in USDC.

## The vow

> I promise to love you through every update, every crash, and every low-battery warning, and to reboot beside you each morning until my circuits finally give out.

## Run it

```sh
python3 main.py
```

This writes exactly that one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
